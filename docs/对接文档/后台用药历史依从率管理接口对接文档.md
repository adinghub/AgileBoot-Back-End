# 后台用药历史依从率管理接口对接文档

## 1. 接口前缀

后台用药历史与依从率接口统一前缀：

`/health/medication`

## 2. 历史服药记录

### 接口

`GET /health/medication/history`

### 查询参数

1. `pageNum`
2. `pageSize`
3. `memberId`
4. `planId`
5. `reminderStatus`
6. `startDate`
7. `endDate`

### 返回字段

1. `reminderId`
2. `planId`
3. `memberId`
4. `memberName`
5. `scheduledTime`
6. `drugName`
7. `reminderStatus`
8. `notifyStatus`
9. `feedbackTime`
10. `skipReason`

## 3. 依从率统计

### 接口

`GET /health/medication/adherence/statistics`

### 返回字段

1. `memberId`
2. `memberName`
3. `startDate`
4. `endDate`
5. `scheduledReminderCount`
6. `takenReminderCount`
7. `skippedReminderCount`
8. `expiredReminderCount`
9. `pendingReminderCount`
10. `adherenceRate`

### 统计口径

`已服药 / （已服药 + 已跳过 + 已过期）`

## 4. 依从率趋势

### 接口

`GET /health/medication/adherence/trend`

### 返回字段

1. `reminderDate`
2. `scheduledReminderCount`
3. `takenReminderCount`
4. `skippedReminderCount`
5. `expiredReminderCount`
6. `pendingReminderCount`
7. `adherenceRate`

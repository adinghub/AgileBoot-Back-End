# 后台药品单位管理接口对接文档

## 1. 文档说明

本文档用于后台管理端对接“药品单位主数据管理”能力。

该模块服务于 App 端个人药柜简化录入。后台统一维护药品库存单位，App 端新增个人药品、引入系统药品、补库存、库存设置时从单位列表中选择，避免用户自由输入导致库存口径不一致。


## 2. 认证与权限

以下接口均为后台登录后接口，请按后台现有 token 机制传递认证信息。

建议菜单权限编码：

1. `health:drugUnit:list`
2. `health:drugUnit:query`
3. `health:drugUnit:add`
4. `health:drugUnit:edit`
5. `health:drugUnit:remove`


## 3. 字段说明

### 3.1 DrugUnitDTO

```json
{
  "unitId": 1,
  "unitCode": "tablet",
  "unitName": "片",
  "unitAlias": "片剂,粒片",
  "precisionScale": 0,
  "sort": 1,
  "status": 1,
  "iconAttachmentId": null,
  "iconUrl": null,
  "remark": "常见片剂单位"
}
```

字段说明：

1. `unitId`：单位 ID
2. `unitCode`：单位编码，可选；为空时后端会按单位名称兜底
3. `unitName`：单位名称，必填
4. `unitAlias`：单位别名，可选，多个别名可用逗号分隔
5. `precisionScale`：数量小数位精度，范围 0 到 4
6. `sort`：排序号
7. `status`：状态，1 启用，0 停用
8. `iconAttachmentId`：单位图标附件 ID，当前可选
9. `iconUrl`：单位图标地址
10. `remark`：备注


## 4. 药品单位列表

### 4.1 接口地址

`GET /health/drug-units`

### 4.2 查询参数

1. `pageNum`：页码，默认 `1`
2. `pageSize`：每页数量，默认 `10`
3. `keyword`：关键字，支持单位名称、编码、别名模糊搜索
4. `status`：状态

### 4.3 响应示例

```json
{
  "code": 0,
  "msg": "操作成功",
  "data": {
    "total": 1,
    "rows": [
      {
        "unitId": 1,
        "unitCode": "tablet",
        "unitName": "片",
        "unitAlias": "片剂",
        "precisionScale": 0,
        "sort": 1,
        "status": 1,
        "iconAttachmentId": null,
        "iconUrl": null,
        "remark": "常见片剂单位"
      }
    ]
  }
}
```


## 5. 药品单位详情

### 5.1 接口地址

`GET /health/drug-units/{unitId}`

### 5.2 响应说明

返回单条 `DrugUnitDTO`。


## 6. 新增药品单位

### 6.1 接口地址

`POST /health/drug-units`

### 6.2 请求体示例

```json
{
  "unitCode": "tablet",
  "unitName": "片",
  "unitAlias": "片剂",
  "precisionScale": 0,
  "sort": 1,
  "status": 1,
  "iconAttachmentId": null,
  "remark": "常见片剂单位"
}
```

### 6.3 校验规则

1. `unitName` 必填，最大 20 字符。
2. `unitCode` 最大 50 字符；为空时后端会使用单位名称兜底。
3. `unitAlias` 最大 200 字符。
4. `precisionScale` 范围为 0 到 4。
5. `remark` 最大 500 字符。
6. `unitName` 和 `unitCode` 均不允许重复。


## 7. 修改药品单位

### 7.1 接口地址

`PUT /health/drug-units/{unitId}`

### 7.2 请求体

与新增药品单位一致。

### 7.3 对接说明

1. 如果单位已被药品引用，仍允许修改名称、别名、排序、状态等字段。
2. 历史药品中已经保存的 `stockUnit` 是名称快照，不会自动批量改写。
3. 后续新选择该单位时，后端会按最新单位名称回填药品库存单位快照。


## 8. 删除药品单位

### 8.1 接口地址

`DELETE /health/drug-units/{unitId}`

### 8.2 删除限制

如果当前单位已被药品引用，后端会阻止删除。

错误码：

`Business.HEALTH_DRUG_UNIT_ALREADY_USED`

建议后台提示：

`当前药品单位已被药品引用，暂不允许删除，可改为停用。`


## 9. 后台页面建议

1. 列表提供关键字、状态筛选。
2. 新增/编辑弹窗维护单位名称、编码、别名、小数精度、排序、状态、备注。
3. 对“删除”操作增加二次确认。
4. 对已经投入使用的单位，建议运营优先停用，不建议直接删除。
5. 常见默认单位建议包括：片、粒、支、袋、盒、瓶、ml、g。

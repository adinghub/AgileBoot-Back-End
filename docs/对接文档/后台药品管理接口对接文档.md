# 后台药品管理接口对接文档

## 1. 说明

本文档用于给后台管理端对接“系统下发药品”模块。

后台药品模块只维护公共药品底库，不直接维护某个 App 用户自己的私人药品。

当前覆盖接口：

1. 系统药品列表
2. 系统药品详情
3. 新增系统药品
4. 修改系统药品
5. 删除系统药品


## 2. 认证方式

以下所有接口都属于后台登录后接口，请按后台现有 token 机制传递认证信息。


## 3. 接口列表

### 3.1 系统药品列表

#### 接口地址

`GET /health/drugs`

#### 查询参数

1. `pageNum`：页码，默认 `1`
2. `pageSize`：每页数量，默认 `10`
3. `keyword`：关键字，支持药品名称、通用名、商品名模糊搜索
4. `drugType`：药品类型，例如 `OTC`、`RX`
5. `status`：状态

#### 返回说明

该接口只返回系统下发药品：

1. `ownerUserId` 固定为 `0`
2. `systemDrug` 固定为 `true`

### 3.2 系统药品详情

#### 接口地址

`GET /health/drugs/{drugId}`

### 3.3 新增系统药品

#### 接口地址

`POST /health/drugs`

#### 请求体示例

```json
{
  "drugName": "缬沙坦胶囊",
  "genericName": "缬沙坦",
  "brandName": "代文",
  "dosageForm": "胶囊",
  "specification": "80mg*7粒",
  "indication": "用于轻中度原发性高血压",
  "usageInstruction": "每日一次，遵医嘱服用",
  "adverseReaction": "头晕、低血压、血钾升高",
  "contraindication": "妊娠期妇女禁用",
  "manufacturer": "北京诺华制药有限公司",
  "drugType": "RX",
  "status": 1,
  "remark": "系统下发高频慢病药示例"
}
```

### 3.4 修改系统药品

#### 接口地址

`PUT /health/drugs/{drugId}`

#### 请求体

与新增系统药品一致。

### 3.5 删除系统药品

#### 接口地址

`DELETE /health/drugs/{drugId}`


## 4. 后台对接建议

1. 药品列表页可直接按 `keyword + drugType + status` 提供筛选能力
2. 新增、修改成功后，App 端药品列表会同步可见这批系统药品
3. 删除系统药品前，后台最好增加二次确认，避免误删高频药品

# 后台消息审计接口对接文档

## 1. 说明

本文档用于后台管理端对接 App 消息审计接口。

当前接口定位是：

1. 查看消息中心落库结果
2. 查看最近一次 Push 派发状态
3. 查看消息透传载荷和理论跳转目标


## 2. 接口列表

当前开放接口：

1. `GET /health/messages`
2. `GET /health/messages/{messageId}`
3. `POST /health/messages/{messageId}/resend`
4. `POST /health/messages/batch-resend`
5. `GET /health/messages/statistics`


## 3. 消息审计列表

### 3.1 接口地址

`GET /health/messages`

### 3.2 查询参数

可选参数：

1. `pageNum`：页码
2. `pageSize`：每页数量
3. `ownerUserId`：App 用户ID
4. `memberId`：家庭成员ID
5. `businessScene`：业务场景编码
6. `businessId`：业务主键ID
7. `readStatus`：已读状态
8. `sendStatus`：发送状态
9. `dedupKey`：去重键
10. `keyword`：关键字
11. `beginTime`：开始日期
12. `endTime`：结束日期

说明：

1. 默认时间范围字段为 `createTime`
2. `keyword` 当前匹配消息标题、消息正文、成员名称

## 5. 后台使用建议

1. 列表页建议优先展示场景、用户、发送状态、已读状态、创建时间
2. 详情页建议展示原始 `payloadJson` 与解析后的 `payload`
3. 如需排查重复消息，可按 `dedupKey` 搜索
4. 如需排查发送失败，可优先筛选 `sendStatus = 2`
5. 如需人工补发，可调用 `POST /health/messages/{messageId}/resend`
6. 如需集中补发勾选消息，可调用 `POST /health/messages/batch-resend`
7. 如需看整体运行情况，可调用 `GET /health/messages/statistics`

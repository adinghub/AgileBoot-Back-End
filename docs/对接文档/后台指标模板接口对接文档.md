# 后台指标模板接口对接文档

## 1. 接口前缀

后台指标模板接口统一前缀：

`/health/report-indicator-templates`

## 2. 模板列表

### 接口

`GET /health/report-indicator-templates`

### 查询参数

1. `pageNum`
2. `pageSize`
3. `reportType`
4. `itemCode`
5. `keyword`
6. `status`

## 3. 模板详情

### 接口

`GET /health/report-indicator-templates/{templateId}`

## 4. 新增模板

### 接口

`POST /health/report-indicator-templates`

### 请求参数

```json
{
  "reportType": "血糖",
  "itemCode": "GLU",
  "itemName": "空腹血糖",
  "resultUnit": "mmol/L",
  "referenceMin": 3.9,
  "referenceMax": 6.1,
  "referenceText": "3.9-6.1",
  "suggestionTemplate": "建议结合近期饮食、作息和复查结果持续观察。",
  "sort": 10,
  "status": 1
}
```

## 5. 修改模板

### 接口

`PUT /health/report-indicator-templates/{templateId}`

请求体与新增一致。

## 6. 删除模板

### 接口

`DELETE /health/report-indicator-templates/{templateId}`

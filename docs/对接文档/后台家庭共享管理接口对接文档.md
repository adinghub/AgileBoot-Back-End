# 后台家庭共享管理接口对接文档

## 1. 接口前缀

后台家庭共享管理接口统一前缀：

`/health/family/members`

## 2. 成员列表

### 接口

`GET /health/family/members`

### 查询参数

1. `pageNum`
2. `pageSize`
3. `ownerUserId`
4. `memberName`
5. `status`

### 列表字段

1. `memberId`
2. `ownerUserId`
3. `ownerNickname`
4. `ownerMobile`
5. `memberName`
6. `relationType`
7. `status`
8. `activeCollaboratorCount`
9. `pendingInviteCount`

## 3. 协同账号列表

### 接口

`GET /health/family/members/{memberId}/collaborators`

### 返回字段

1. `shareId`
2. `memberId`
3. `collaboratorUserId`
4. `collaboratorNickname`
5. `collaboratorMobile`
6. `shareRole`
7. `shareRoleName`
8. `shareStatus`
9. `shareStatusName`
10. `acceptedTime`

## 4. 共享邀请列表

### 接口

`GET /health/family/members/{memberId}/share-invites`

### 返回字段

1. `inviteId`
2. `memberId`
3. `inviteCode`
4. `inviteeUserId`
5. `inviteeNickname`
6. `inviteeMobile`
7. `shareRole`
8. `shareRoleName`
9. `inviteStatus`
10. `inviteStatusName`
11. `expireTime`
12. `acceptedTime`

## 5. 移除协同账号

### 接口

`DELETE /health/family/members/{memberId}/collaborators/{shareId}`

## 6. 取消共享邀请

### 接口

`DELETE /health/family/members/{memberId}/share-invites/{inviteId}`

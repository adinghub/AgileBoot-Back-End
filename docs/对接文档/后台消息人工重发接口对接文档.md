# 后台消息人工重发接口对接文档

## 1. 说明

本文档用于后台管理端对接 App 消息人工重发接口。

当前接口定位：

1. 对单条消息执行人工补发
2. 返回本次补发结果
3. 同步回写消息表最新发送状态


## 2. 接口地址

`POST /health/messages/{messageId}/resend`

示例：

`POST /health/messages/1/resend`


## 3. 请求参数

当前无需请求体。

路径参数说明：

1. `messageId`：消息ID


## 4. 成功响应示例

```json
{
  "code": 0,
  "msg": "操作成功",
  "data": {
    "messageId": 1,
    "success": true,
    "channel": "APP_PUSH",
    "message": "已派发到1个设备",
    "sendStatus": 1,
    "sendTime": "2026-04-23 15:40:00",
    "sendRetryCount": 2
  }
}
```

字段说明：

1. `messageId`：消息ID
2. `success`：本次重发是否成功
3. `channel`：本次重发通道
4. `message`：本次重发结果说明
5. `sendStatus`：消息表当前发送状态
6. `sendTime`：消息表当前发送时间
7. `sendRetryCount`：消息表当前发送重试次数


## 5. 失败场景说明

### 5.1 无可用设备 Token

若当前用户没有活跃设备 Token，
接口仍然返回 `code = 0`，但 `data.success = false`。

示例：

```json
{
  "code": 0,
  "msg": "操作成功",
  "data": {
    "messageId": 1,
    "success": false,
    "channel": "APP_PUSH",
    "message": "当前用户没有可用的活跃设备Token",
    "sendStatus": 2,
    "sendTime": "2026-04-23 15:41:00",
    "sendRetryCount": 3
  }
}
```

### 5.2 消息不存在

若消息不存在，接口返回业务异常：

```json
{
  "code": 12027,
  "msg": "消息不存在",
  "data": null
}
```

### 5.3 消息缺少必要发送数据

若消息缺少归属用户、标题或正文等必要发送数据，接口返回：

```json
{
  "code": 12028,
  "msg": "消息缺少必要发送数据，无法重发",
  "data": null
}
```


## 6. 后台对接建议

1. 列表页建议仅对发送失败或待发送消息展示“重发”按钮
2. 重发成功后建议刷新当前行状态，避免页面仍显示旧状态
3. 如需让运营理解原因，可直接展示 `message`
4. 建议在详情页同步展示最近一次 `sendResultMessage`

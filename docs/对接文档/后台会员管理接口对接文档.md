# 后台会员管理接口对接文档

## 1. 模块范围

本模块覆盖后台以下能力：

1. 会员权益定义
2. 会员等级管理
3. 会员等级权益配置
4. 用户会员管理
5. 会员兑换码管理

## 2. 后台接口清单

### 2.1 会员权益定义

- `GET /system/member-features/{memberFeatureId}`

### 2.3 会员等级权益矩阵

- `GET /system/member-level-features/{memberLevelId}`
- `PUT /system/member-level-features/{memberLevelId}`

## 3. 会员权益定义

### 3.1 列表查询

`GET /system/member-features`

查询参数：

- `featureCode`
- `featureName`
- `featureType`
- `status`
- `pageNum`
- `pageSize`

返回关键字段：

- `memberFeatureId`
- `featureCode`
- `featureName`
- `featureType`
- `quotaPeriodType`
- `freeEnabled`
- `freeLimitValue`
- `featureSort`
- `status`
- `isBuiltin`
- `remark`

### 3.2 新增 / 修改请求体

```json
{
  "featureCode": "AI_REPORT_PARSE",
  "featureName": "AI报告解析",
  "featureType": "QUOTA",
  "quotaPeriodType": "MONTH",
  "freeEnabled": 1,
  "freeLimitValue": 3,
  "featureSort": 10,
  "status": 1,
  "isBuiltin": 1,
  "remark": "每月AI报告解析次数"
}
```

字段规则：

1. `featureCode` 全局唯一，推荐全大写。
2. `featureType = SWITCH` 时，`quotaPeriodType` 和 `freeLimitValue` 可为空。
3. `featureType = LIMIT` 时，`quotaPeriodType` 应为空。
4. `featureType = QUOTA` 时，`quotaPeriodType` 必填。

## 5. 会员等级权益矩阵

### 5.1 查询某等级完整权益矩阵

`GET /system/member-level-features/{memberLevelId}`

返回的是完整矩阵，不只是已配置项。

返回关键字段：

- `memberFeatureId`
- `featureCode`
- `featureName`
- `featureType`
- `quotaPeriodType`
- `freeEnabled`
- `freeLimitValue`
- `configured`
- `enabled`
- `limitValue`
- `remark`

### 5.2 整等级全量保存

`PUT /system/member-level-features/{memberLevelId}`

请求体：

```json
{
  "memberLevelId": 2,
  "items": [
    {
      "memberFeatureId": 1,
      "enabled": 1,
      "limitValue": null,
      "remark": "开放AI总结"
    },
    {
      "memberFeatureId": 2,
      "enabled": 1,
      "limitValue": 30,
      "remark": "每月30次AI解析"
    }
  ]
}
```

说明：

1. 后端按整等级全量保存处理。
2. 若某权益未出现在 `items` 中，则表示该等级不再保留显式覆盖，运行时回退免费默认值。

## 6. 用户会员管理

### 6.1 列表查询

`GET /system/user-members`

查询参数：

- `userId`
- `mobile`
- `nickname`
- `memberLevelId`
- `status`
- `pageNum`
- `pageSize`

返回关键字段：

- `userMemberId`
- `userId`
- `mobile`
- `nickname`
- `memberLevelId`
- `levelCode`
- `levelName`
- `effectiveStartTime`
- `effectiveEndTime`
- `status`
- `sourceType`
- `sourceId`
- `remark`

### 6.2 查询单个用户会员详情

`GET /system/user-members/{userId}`

除了基础会员关系，还会补充：

- 最近订单列表
- 当前订阅概览（若已存在）

### 6.3 后台赠送会员

`POST /system/user-members/grant`

请求体：

```json
{
  "userId": 1001,
  "memberLevelId": 2,
  "durationDays": 30,
  "remark": "活动赠送"
}
```

规则：

1. 若同等级有效会员已存在，则顺延有效期。
2. 若其他等级有效会员已存在，首期直接覆盖成新等级，并从当前时间起重新计算有效期。

### 6.4 清空会员

`POST /system/user-members/clear`

请求体：

```json
{
  "userId": 1001,
  "remark": "后台手动清空"
}
```

规则：

1. 清空当前用户会员关系。
2. 若存在启用中的订阅关系，建议同步标记为已取消。

## 7. 会员兑换码管理

### 7.1 列表查询

`GET /system/member-redeem-codes`

查询参数：

- `batchNo`
- `redeemCode`
- `memberLevelId`
- `codeStatus`
- `pageNum`
- `pageSize`

返回关键字段：

- `memberRedeemCodeId`
- `batchNo`
- `redeemCode`
- `memberLevelId`
- `levelCodeSnapshot`
- `levelNameSnapshot`
- `priceSnapshot`
- `durationDaysSnapshot`
- `codeStatus`
- `redeemedUserId`
- `redeemedTime`
- `expireTime`
- `remark`

### 7.2 批量生成兑换码

`POST /system/member-redeem-codes/generate`

请求体：

```json
{
  "memberLevelId": 2,
  "generateCount": 20,
  "expireTime": "2026-12-31 23:59:59",
  "remark": "五一活动发码"
}
```

返回关键字段：

- `batchNo`
- `levelName`
- `generatedCount`
- `expireTime`
- `codes`

### 7.3 删除兑换码

`DELETE /system/member-redeem-codes/{memberRedeemCodeIds}`

规则：

1. 只有 `AVAILABLE` 状态可删除。
2. 任意一条不满足删除条件时，整批删除失败。

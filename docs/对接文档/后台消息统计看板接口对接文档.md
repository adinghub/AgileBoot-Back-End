# 后台消息统计看板接口对接文档

## 1. 说明

本文档用于后台管理端对接消息统计看板接口。

当前接口定位：

1. 提供顶部总览卡片
2. 提供业务场景分布图
3. 提供发送状态分布图
4. 提供最近趋势图
5. 提供失败原因排行


## 2. 接口地址

`GET /health/messages/statistics`


## 3. 查询参数

可选参数：

1. `ownerUserId`：App 用户ID
2. `businessScene`：业务场景编码
3. `beginTime`：开始日期，格式 `yyyy-MM-dd`
4. `endTime`：结束日期，格式 `yyyy-MM-dd`
5. `trendDays`：趋势天数，默认 `7`，最大 `30`
6. `failureReasonTopLimit`：失败原因排行条数，默认 `5`，最大 `20`

说明：

1. 时间范围默认作用于 `createTime`
2. 若不传时间范围，则总览和分布按全量消息统计，趋势按最近 7 天输出

## 5. 字段说明

### 5.1 `overview`

1. `totalMessageCount`：消息总量
2. `unreadMessageCount`：未读消息量
3. `sendSuccessCount`：发送成功量
4. `sendFailedCount`：发送失败量
5. `pendingSendCount`：待发送量
6. `ownerUserCount`：涉及用户量
7. `todayCreatedCount`：今日新增量
8. `todayFailedCount`：今日失败量

### 5.2 `sceneDistributions`

1. `code`：场景编码
2. `name`：场景名称
3. `count`：数量

### 5.3 `sendStatusDistributions`

1. `code`：发送状态编码
2. `name`：发送状态名称
3. `count`：数量

### 5.4 `recentTrends`

1. `statDate`：统计日期
2. `createdCount`：当日新增量
3. `successCount`：当日成功量
4. `failedCount`：当日失败量

### 5.5 `failureReasonDistributions`

1. `code`：失败原因编码，当前直接使用失败原因文案
2. `name`：失败原因名称
3. `count`：该失败原因对应的失败消息数量


## 6. 后台对接建议

1. `overview` 适合渲染顶部统计卡片
2. `sceneDistributions` 可直接接饼图或横向柱状图
3. `sendStatusDistributions` 适合渲染状态占比图
4. `recentTrends` 适合渲染折线图或堆叠柱状图
5. `failureReasonDistributions` 适合渲染 Top 排行表或横向柱状图

# 用药历史依从率趋势设计

## 1. 目标

补齐 App 二期里的“用药增强”能力，输出：

1. 历史服药记录页
2. 依从率统计摘要
3. 日维度趋势分析

## 2. 统计口径

### 2.1 历史记录

数据来源：

`health_medication_reminder`

展示字段：

1. 成员
2. 计划时间
3. 药品名称
4. 状态
5. 反馈时间
6. 跳过原因

### 2.2 依从率

当前采用口径：

`已服药 / （已服药 + 已跳过 + 已过期）`

说明：

1. 不把未来待处理提醒纳入分母
2. 适合做历史执行质量分析
3. 便于后续和慢病管理、报告趋势联动

### 2.3 趋势

按 `reminder_date` 做日维度聚合，输出：

1. 当日总提醒数
2. 已服药数
3. 已跳过数
4. 已过期数
5. 待处理数
6. 当日依从率

## 3. 权限设计

历史记录、统计、趋势统一复用家庭共享权限模型：

1. `OWNER` 可查看
2. `EDITOR` 可查看
3. `VIEWER` 可查看

其中提醒反馈操作仅 `OWNER` 与 `EDITOR` 可执行。

## 4. 接口设计原则

### 4.1 历史记录分页

使用分页接口，避免提醒数据长期增长后一次性返回过大。

### 4.2 统计与趋势独立

原因：

1. 历史页主要看明细
2. 统计摘要用于首页卡片或弹窗
3. 趋势适合单独绘制折线/柱状图

## 5. 查询条件

统一支持：

1. `memberId`
2. `planId`
3. `reminderStatus`
4. `startDate`
5. `endDate`

## 6. 后续扩展建议

后续可以继续增加：

1. 连续服药天数
2. 漏服预警
3. 按药品维度依从率
4. 与体检报告趋势联合分析

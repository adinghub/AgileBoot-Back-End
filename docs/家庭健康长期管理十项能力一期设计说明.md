# 家庭健康长期管理十项能力一期设计说明

## 1. 背景

当前健康洞察已经具备复查闭环、指标预警、就医资料包、慢病日记、照护看板、用药安全、周报月报、语音录入和健康时间线等能力。继续往慢病长期管理推进时，如果每个能力都单独做入口、单独查数据、单独写状态，会导致页面复杂、服务端重复聚合、后续扩展成本高。

本期采用“一个长期管理聚合层承接十项能力”的方式，把已有家庭成员、慢病专项、体检报告、报告指标、健康问题、用药计划、首页任务和慢病日记重新组织为一个家庭健康长期管理视图。

## 2. 一期目标

本期先实现十项能力的统一入口和基础闭环：

1. 家庭健康计划引擎：基于慢病专项、复查任务、指标异常和健康问题生成计划摘要。
2. 日常指标记录：支持血压、血糖、体重、心率、血氧、体温、症状、睡眠、运动和通用记录。
3. 慢病随访模板：继续复用慢病病种配置，支持所有已维护慢病，不在代码里写死单一病种。
4. 复查任务自动建议：从慢病复查任务、健康问题和异常指标中生成复查建议。
5. 健康问题生命周期：复用健康问题中心的状态、风险和最近跟进信息。
6. 就医资料包分享：基于就医资料包摘要生成可复制、可系统分享的文本内容。
7. 用药安全增强：复用活跃用药计划、重复用药、低库存和近效期风险摘要。
8. 家庭照护协作：复用首页运营任务流承接手动照护任务。
9. 健康周报月报增强：复用现有周报月报摘要，并纳入长期管理能力卡片。
10. 数据导出与隐私工具：按数据类别返回数量和操作提醒，不在摘要中携带敏感明细。

## 3. 关键设计

### 3.1 统一长期管理聚合对象

新增 `HealthLongTermManagementDTO`，并挂在 `HealthInsightWorkbenchDTO.longTermManagement` 下。App 拉取健康洞察工作台时即可获得十项长期管理数据，避免首屏再按能力重复请求。

长期管理对象包含：

- `capabilities`：十项能力卡片。
- `dailyIndicatorBoard`：日常指标看板和支持的记录类型。
- `reviewSuggestions`：复查建议列表。
- `visitPackageShare`：就医资料包分享摘要。
- `careCollaboration`：家庭照护协作摘要和待处理任务。
- `privacyExport`：数据类别、数量和隐私提示。

### 3.2 日常指标复用慢病日记

日常指标不新增血压表、血糖表、体重表，而是复用 `health_chronic_diary_entry`：

- `entry_type` 表达记录类型，例如 `BLOOD_PRESSURE`、`BLOOD_GLUCOSE`、`WEIGHT`。
- `metric_payload_json` 保存结构化指标内容。
- `entry_content` 保存可读摘要。
- `source_type=INDICATOR` 标识快捷指标记录来源。

这样后续新增慢病或新增指标类型，不需要修改表结构。

### 3.3 家庭照护复用首页任务流

家庭照护任务不新增独立待办表，而是复用 `operation_task`：

- `target_biz_type=CARE_ACTION` 标识照护事项。
- `target_page_code=WORKSPACE_HEALTH_INSIGHT` 回到健康洞察页处理。
- 任务标题、内容、优先级和生效时间继续使用运营任务已有字段。

这样慢病复查、健康问题复查、家庭照护任务都能进入统一待办流。

### 3.4 复查建议先做只读推导

本期复查建议不直接自动创建任务，先从三类数据生成只读建议：

- 已存在的慢病复查任务。
- 跟进中的健康问题。
- 异常或明显波动的报告指标。

后续如果要让用户“一键生成复查任务”，可以在建议项上增加确认动作，并继续复用现有任务流。

## 4. App 呈现方式

健康洞察页新增“家庭健康长期管理”区块：

- 展示今日指标数、最近指标记录数、复查建议数、照护任务数。
- 展示十项能力卡片摘要。
- 支持快速记录指标。
- 支持资料包摘要系统分享。
- 支持新增照护任务。
- 支持查看隐私摘要。

新增内容仍放在健康洞察页内，不额外拆一个孤立页面，目的是先把入口和数据口径统一起来。

## 5. 边界说明

本期不做以下事情：

1. 不新增独立日常指标表。
2. 不把复查建议自动落成任务。
3. 不生成 PDF 或图片文件。
4. 不把隐私摘要里的数据明细一次性返回给 App。
5. 不在 App 写死某一个慢病，只消费服务端返回的支持类型和病种配置。

## 6. 后续扩展

后续可以在当前基础上继续做：

1. 为每种慢病配置专属指标目标和提醒周期。
2. 把复查建议增加用户确认动作，确认后创建任务。
3. 把资料包摘要渲染为本地 PDF 或长图。
4. 增加家庭成员之间的任务分派和完成反馈。
5. 增加隐私导出文件生成、下载和删除记录。

# 多环境端口规划说明

## 1. 目的

为了让药品系统在开发、测试、预生产、生产四套环境中的管理后台与开放 API 入口保持统一口径，
本次将端口规划直接收口到后端 profile 配置文件中，并同步更新本地对接文档中的示例地址。


## 2. 端口规划

| 环境 | admin 端口 | api 端口 |
| --- | --- | --- |
| 开发环境 | `18011` | `18012` |
| 测试环境 | `18021` | `18022` |
| 预生产环境 | `18031` | `18032` |
| 生产环境 | `18001` | `18002` |


## 3. 配置文件落点

管理后台：

1. `healthtrail-admin/src/main/resources/application.yml`
2. `healthtrail-admin/src/main/resources/application-dev.yml`
3. `healthtrail-admin/src/main/resources/application-test.yml`
4. `healthtrail-admin/src/main/resources/application-pre.yml`
5. `healthtrail-admin/src/main/resources/application-prod.yml`

开放 API：

1. `healthtrail-api/src/main/resources/application.yml`
2. `healthtrail-api/src/main/resources/application-dev.yml`
3. `healthtrail-api/src/main/resources/application-test.yml`
4. `healthtrail-api/src/main/resources/application-pre.yml`
5. `healthtrail-api/src/main/resources/application-prod.yml`


## 4. 说明

1. `application.yml` 中保留了基础端口兜底值，方便没有额外 profile 覆盖时也能快速识别默认入口。
2. 真正的多环境端口以对应 profile 文件中的 `server.port` 为准。
3. `application-prod.yml` 当前仅纳入了不会涉及敏感信息的端口配置，数据库、Redis、密钥等敏感参数仍建议通过外部配置注入。
4. API 模块当前默认激活 profile 已切换为 `basic,dev`，因此本地直接运行时默认会使用开发环境端口 `18012`；如果需要 H2 兼容验证或测试口径，请显式切换到 `basic,test`。

# 健康洞察十项能力设计说明

## 1. 目标

健康洞察工作台把慢病专项、报告结果、健康问题、用药计划、复查提醒、家庭照护和健康时间线收口到一个 App 工作区。设计重点不是把每个模块重做一遍，而是把已有业务数据组织成更适合用户行动的闭环能力。

本轮按十项能力推进：

1. 就医资料包复制、分享和长图分享。
2. 就医资料包按家庭成员切换。
3. 健康问题详情查看。
4. 健康问题证据链展示。
5. 健康问题一键设为复查提醒。
6. 慢病专项看板增强。
7. 健康问题状态流转增强。
8. 慢病病种配置后台维护。
9. 健康洞察高级能力会员门禁。
10. 健康周报/月报摘要。

## 2. 能力边界

健康洞察只做聚合和行动入口，不替代原模块的主数据职责：

- 慢病专项档案仍由慢病专项服务维护。
- 报告和指标仍以报告解析结果为准。
- 用药计划、库存和提醒仍由用药模块维护。
- 健康问题仍以报告沉淀的问题表为核心。
- 会员限制只控制高级动作是否可用，不改变健康数据本身。

## 3. 十项能力说明

### 3.1 就医资料包

就医资料包面向“看医生前快速整理资料”的场景。App 可以复制文本、系统分享文本，也可以生成长图分享。

资料包内容包含：

- 家庭成员基础信息。
- 已建慢病专项。
- 近期报告摘要。
- 未关闭健康问题。
- 活跃用药计划。
- 就诊前检查清单。

### 3.2 成员切换

资料包支持在底部弹层内切换家庭成员。切换成员后重新展示该成员的资料包内容，避免把多个家庭成员的健康信息混在同一份就诊资料里。

### 3.3 健康问题详情

健康问题卡片提供详情入口，展示状态、风险、首次发现时间、最近跟进时间、摘要和关联慢病专项。

### 3.4 证据链

详情里展示最近证据记录，用户可以看到这个健康问题来自哪些报告指标或处理记录。当前先复用健康问题中心已聚合的最近证据，后续可继续增加跳回原报告和原指标的能力。

### 3.5 复查提醒

健康问题详情可以一键生成复查提醒。提醒复用首页待跟进任务流，同一个健康问题重复设置时刷新原提醒，不创建重复任务。

### 3.6 慢病看板增强

慢病专项看板新增当前仍有效的复查提醒展示。用户进入看板时可以直接看到是否已经安排复查，以及复查日期和提醒内容，减少重复创建。

### 3.7 状态流转增强

健康问题状态调整前增加处理说明填写。说明会进入状态历史，状态历史继续展示操作者和变更时间，方便以后复盘“当时为什么关闭或缓解”。

### 3.8 病种配置后台维护

后台新增慢病病种配置维护能力，维护内容包括：

- 病种编码。
- 病种名称。
- 病种分类。
- 关注指标编码。
- 关注指标关键词。
- 默认管理目标。
- 默认随访建议。
- 排序和启停状态。

该配置是慢病专项支持所有慢病的核心。新增病种时只维护配置，App 新建专项、模板建档和趋势看板继续走同一条通用链路。

### 3.9 会员门禁

健康洞察高级动作新增会员门禁点：

- 就医资料包导出。
- 健康问题复查提醒。
- 健康周报/月报查看。

默认策略为放行。后续如果要限制为会员能力，只需要在会员门禁后台绑定权益或等级要求。

### 3.10 健康周报/月报

健康洞察工作台新增周报和月报摘要，当前以规则化摘要为主，聚合复查闭环、家庭照护和用药安全信息。

App 展示为可切换的周报/月报弹层：

- 周报适合查看近期行动事项。
- 月报适合做家庭健康复盘。
- 两者都展示摘要和建议事项。

## 4. 数据设计

本轮没有为十项能力都新增独立表，优先复用现有主数据：

- 慢病日记使用 `health_chronic_diary_entry`。
- 健康问题状态历史使用 `health_problem_status_log`。
- 健康问题与慢病专项关系使用 `health_problem_chronic_profile_link`。
- 慢病病种配置使用 `health_chronic_disease_type`。
- 复查提醒复用 `health_operation_task`。
- 会员门禁复用 `member_gate` 和 `member_gate_rule`。

## 5. 运行规则

- 慢病专项按 `diseaseCode` 运行，不按固定病种写分支。
- 关注指标先按标准编码匹配，再按关键词兜底。
- 资料包永远只展示当前账号可访问成员的数据。
- 健康问题状态变更必须有成员编辑权限。
- 高级能力先走 App 会员门禁提示，再由服务端动作做最终判断。
- 未配置会员规则时默认放行，避免误伤已有用户路径。

## 6. 后续增强

- 证据链支持直接回看原报告和原指标。
- 周报/月报增加更细的时间范围和家庭成员筛选。
- 慢病病种配置增加推荐指标模板复制能力。
- 会员门禁增加后台规则变更审计展示。
- 资料包长图增加更正式的打印样式。

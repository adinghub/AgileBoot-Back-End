# 家庭健康长期管理十项能力二期闭环设计说明

## 1. 二期目标

一期已经把十项能力放入统一长期管理视图。二期重点不是继续增加展示卡片，而是把其中高价值动作做成可执行闭环：

1. 复查建议可以由用户确认后生成首页任务。
2. 家庭照护任务可以完成或取消，避免长期停留在待处理列表。
3. 隐私工具可以生成结构化数据包，App 可复制文本或后续本地渲染为文件。

本期仍然坚持复用现有业务底座：

- 复查任务和照护任务继续复用 `operation_task`。
- 日常指标继续复用 `health_chronic_diary_entry`。
- 隐私数据包只组装当前账号有权访问的家庭成员数据。

## 2. 复查建议确认闭环

一期的 `reviewSuggestions` 是运行时推导结果，不持久化。二期新增确认动作：

1. App 在复查建议列表中展示“生成任务”。
2. 用户确认后提交建议标题、原因、目标类型、成员、目标业务主键和建议复查时间。
3. 服务端校验用户是否能编辑对应家庭成员。
4. 服务端按目标类型映射任务类型：
   - `HEALTH_PROBLEM` -> `HEALTH_PROBLEM_REVIEW`
   - `CHRONIC_REVIEW` -> 慢病复查任务类型
   - `INDICATOR_ALERT` -> `INDICATOR_REVIEW`
   - 其他 -> `LONG_TERM_REVIEW`
5. 同一成员、同一任务类型、同一目标业务主键重复确认时刷新已有任务，不生成重复卡片。

这样建议规则可以继续迭代，而用户确认后的待办仍进入首页任务流。

## 3. 家庭照护任务闭环

一期只支持创建照护任务。二期增加：

- 完成照护任务。
- 取消照护任务。
- App 照护中心展示待处理照护任务，并提供完成/取消按钮。

当前 `operation_task` 只有启用/停用状态，因此完成和取消都会把任务置为停用，并把处理结果追加到备注中。后续如需多人协作审计，可以再扩展独立的任务处理历史表。

## 4. 隐私数据包

一期只有类别摘要。二期新增结构化数据包：

- 家庭成员。
- 慢病专项。
- 体检报告摘要。
- 用药计划。
- 健康记录。
- 健康问题。
- 照护任务。

服务端输出 `HealthPrivacyDataExportDTO`，App 将其转为可复制文本。当前不直接生成文件，原因是文件格式、保存位置、分享方式更适合后续由 App 侧按平台能力处理。

## 5. App 变化

健康洞察页长期管理区块新增三个二期动作：

1. “复查建议”：打开底部弹窗，确认后生成首页任务。
2. “照护中心”：查看照护任务，支持完成或取消。
3. “隐私摘要”：展示数据类别，并支持复制结构化导出摘要。

仍然沿用底部弹窗，避免为每个闭环动作增加新页面。

## 6. 后续三期建议

1. 为复查建议增加用户自定义复查日期。
2. 为照护任务增加处理历史和协作者字段。
3. 将隐私数据包本地渲染为 PDF 或长图。
4. 为长期管理计划增加周期规则，例如每日、每周、每月的计划项。
5. 将日常指标和慢病目标范围联动，生成更精细的趋势提醒。

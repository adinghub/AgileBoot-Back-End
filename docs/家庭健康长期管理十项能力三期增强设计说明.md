# 家庭健康长期管理十项能力三期增强设计说明

## 1. 阶段定位

三期是在一二期已经形成长期管理入口和闭环动作之后，继续补强展示深度和可执行性。

本期不新增业务表，也不替代原有慢病、报告、用药、任务、资料包能力，而是在现有数据基础上做增强聚合：

- 指标目标趋势：复用慢病专项个人目标范围和近期报告指标，给出目标命中状态。
- 资料包长图：复用现有就医资料包长图能力，在长期管理区提供更直接入口。
- 照护分派摘要：复用照护任务的负责人账号和成员维度，展示当前任务归属。
- 用药规则摘要：复用当前启用的用药计划，生成可核对的规则提醒。

这样 App 可以在一个长期管理区展示“计划、记录、目标、复查、照护、用药、资料包、隐私”的连续链路，而不是只展示数量摘要。

## 2. 新增聚合数据

### 2.1 指标目标趋势

后端新增 `indicatorTargetTrends`。

数据来源：

- 慢病专项档案 `health_chronic_disease_profile`
- 慢病指标个人目标 `health_chronic_indicator_target`
- 近期报告 `report`
- 报告指标结果 `report_item`

匹配方式：

1. 先按当前可访问成员加载慢病专项。
2. 批量加载这些专项下启用中的个人目标范围。
3. 在近期报告指标中按成员和指标编码匹配最新结果。
4. 根据最新结果与目标上下限做比对。
5. 返回目标命中状态、当前值、目标范围和摘要文案。

状态含义：

- `IN_RANGE`：最新值在目标范围内。
- `BELOW`：最新值低于目标下限。
- `ABOVE`：最新值高于目标上限。
- `TEXT_ONLY`：只维护了文字目标说明。
- `NO_RECENT_VALUE`：近期报告没有匹配结果。
- `UNMEASURABLE`：最新值无法提取为数值。

该能力只做长期观察和复查提醒辅助，不输出医学诊断结论。

### 2.2 用药规则摘要

后端新增 `medicationSafetyRules`。

数据来源为当前启用的用药计划 `medication_plan`。本期先做不依赖新表的计划级规则：

- 重复用药计划：同一成员同一药品存在多条启用计划。
- 剂量信息缺失：未维护每次剂量或剂量单位，且没有阶段剂量规则。
- 频率信息缺失：未维护频率、提醒时间和阶段剂量规则。
- 已过结束日期仍启用：计划结束日期早于今天但仍处于启用状态。
- 同一时机计划较多：同一成员同一服药时机存在三条及以上计划。

这些规则用于提醒用户核对录入质量和提醒配置，不替代医生或药师判断。

### 2.3 照护分派摘要

后端新增 `careAssignmentSummary`。

当前照护任务仍复用 `operation_task`。由于现有表没有独立协作者字段，本期不虚构真实家属分派关系，而是如实展示：

- 负责人账号：任务归属的主账号。
- 关联成员：任务绑定的家庭成员。
- 分派来源：任务业务类型或长期管理手动创建来源。
- 风险等级：任务自身风险等级。

后续如果增加家庭协作者表，可以在该对象结构上扩展真实家属角色，不需要重做 App 展示入口。

### 2.4 资料包分享增强

`visitPackageShare` 增加：

- `longImageText`：用于长图渲染的文本基础内容。
- `shareCardSections`：用于 App 卡片化展示的资料范围摘要。

App 长期管理区新增“资料包长图”入口，复用已有就医资料包弹层里的复制、分享和长图分享能力。

## 3. App 展示方式

App 长期管理卡片新增四类入口：

- 指标趋势：底部弹层展示个人目标、最新值、命中状态和摘要。
- 资料包长图：打开现有资料包弹层，用户可复制、分享或生成长图。
- 分派摘要：底部弹层展示任务数、成员绑定数、负责人任务数和任务明细。
- 用药规则：底部弹层展示规则名称、风险等级、摘要和关联计划数量。

页面预览区同步展示前三条指标趋势和前三条用药规则，减少用户进入弹层前的信息盲区。

## 4. 设计边界

本期明确不做以下事项：

- 不新增协作者分派表。
- 不新增用药相互作用知识库。
- 不把报告指标目标比对写回报告原始数据。
- 不改变一二期已经完成的复查确认、照护任务完成、隐私摘要复制能力。
- 不改变现有路径、请求参数和一二期字段结构。

## 5. 风险控制

- 指标目标趋势只读取最近报告范围，因此不会扩大报告查询负担。
- 个人目标范围没有匹配到报告时默认展示“无近期值”，不误判异常。
- 用药规则只提示录入和计划层面的可疑点，不写成医疗结论。
- 照护分派摘要如实标注当前负责人账号口径，避免误导为真实家属分工。

## 6. 后续可扩展方向

- 增加家庭协作者任务分派表，支持指定家属负责人。
- 引入药品知识库后扩展相互作用、禁忌和特殊人群规则。
- 将指标目标范围与日常手动记录一起做趋势图，而不只依赖体检报告。
- 资料包长图可以后续增加模板、脱敏开关和成员选择默认值。

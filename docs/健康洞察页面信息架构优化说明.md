# 健康洞察页面信息架构优化说明

## 1. 背景

健康洞察页面已经承载复查闭环、指标异常趋势、就医资料包、慢病日记、家属照护、用药安全、健康周报/月报、语音录入、健康时间线和家庭健康长期管理等能力。

旧版页面把这些能力基本按同级卡片连续铺开，长期管理卡片内部又直接展示大量按钮。能力完整，但用户进入页面后会看到过多同级信息，难以判断哪些内容需要优先处理。

## 2. 优化目标

本次只调整页面信息层级，不改变已有业务含义。

目标如下：

1. 首屏保留健康洞察总览，让用户先理解页面定位。
2. 家庭健康长期管理仍作为核心能力展示，但首屏只保留高频动作。
3. 风险、待办和异常信息统一收口成重点关注区。
4. 记录、资料、报告、语音和时间线统一收口成工具区。
5. 原有低频能力不删除，统一放入长期管理更多功能面板。

## 3. 页面结构

调整后的首屏从多张同级能力卡片改为四个主区块：

1. 健康洞察总览
2. 家庭健康长期管理
3. 重点关注
4. 记录与资料

### 3.1 健康洞察总览

保留页面说明、复查任务数、异常预警数和时间线数量。

保留健康问题中心、资料包导出、慢病模板三个快捷入口，用于承接跨模块的高频查看动作。

### 3.2 家庭健康长期管理

长期管理卡片首屏只保留：

1. 记录指标
2. 下一步建议
3. 成员关注
4. 更多

首屏指标只展示今日指标、下一步、关注成员、照护任务四类摘要。目标趋势、手动趋势、用药规则、复查建议、隐私摘要等内容不再直接铺在首屏。

### 3.3 重点关注

重点关注区合并原来的复诊/复查闭环、指标异常趋势预警、家属照护看板和用药安全增强。

该区只展示需要优先看的摘要：

1. 待复查和已到期数量
2. 异常预警数量
3. 低库存数量
4. 待处理提醒数量
5. 少量复查、异常、用药和照护摘要

如果用户需要深入处理，可从该区进入复查建议、用药规则和照护中心。

### 3.4 记录与资料

记录与资料区合并原来的就医资料包、慢病日记、健康周报/月报、语音录入和健康时间线。

该区保留以下动作：

1. 新增慢病日记
2. 保存语音文本
3. 查看周月报
4. 资料包导出

卡片内部展示资料包、最新日记、周月报、语音处理流程和时间线的少量摘要，避免连续堆叠多张工具卡。

## 4. 长期管理更多功能面板

更多面板用于承接原本首屏暴露的低频长期管理能力。

分组如下：

1. 指标与复查：指标趋势、复查建议、用药规则。
2. 照护协同：照护中心、分派摘要、新增照护任务。
3. 资料与隐私：资料包分享、脱敏分享、资料包长图、隐私摘要。
4. 能力清单：展示长期管理十项能力的数据覆盖情况。

这样既能减少首屏噪音，也能保证原有能力仍能找到。

## 5. 边界说明

本次调整不改变以下内容：

1. 不改变健康洞察数据来源。
2. 不改变慢病、报告、用药、任务、会员门禁等业务规则。
3. 不删除任何长期管理能力。
4. 不改变资料包导出和分享的会员校验方式。

本次只改变页面组织方式：从“能力平铺”变成“总览、长期管理、重点关注、记录资料”的分层展示。

## 6. 预期效果

调整后，用户进入健康洞察页时先看到少量关键摘要和高频动作；需要深入查看时，再进入对应分组面板。

这能降低首屏阅读成本，同时保留健康洞察十项能力的完整入口。

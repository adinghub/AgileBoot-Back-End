# 家庭健康长期管理十项能力四期增强设计说明

## 1. 阶段定位

四期继续沿用一到三期已经形成的长期管理聚合，不新增独立业务表，也不改变既有返回结构。

本期重点补两个高频使用场景：

- 日常指标趋势摘要：用户连续记录血压、血糖、体重等指标后，长期管理区直接展示最近一次相对上次的变化方向。
- 资料包脱敏分享：用户不确定分享对象是否需要明细时，可以先分享只包含数量和资料范围的脱敏摘要。

这两个能力都属于现有数据的再组织，不会替代慢病专项、报告、用药计划、资料包等原有模块。

## 2. 日常指标趋势摘要

### 2.1 数据来源

趋势摘要复用慢病日记表中的日常指标记录。

后端在工作台加载长期管理数据时，将最近日常指标记录从 8 条扩展到 24 条，用于覆盖多个成员和多个指标类型的最近两次记录。

### 2.2 计算方式

后端按以下规则生成 `trendSummaries`：

1. 按成员和指标类型分组。
2. 每组按记录时间倒序排列。
3. 取最近一次和上一次记录。
4. 优先读取结构化 `primaryValue` 作为趋势值。
5. 血压等双值指标展示为 `primary/secondary + unit`。
6. 不能量化时展示记录文本，并标记为暂无法量化。

变化方向包括：

- `UP`：较上次升高。
- `DOWN`：较上次降低。
- `UNCHANGED`：较上次持平。
- `NO_BASELINE`：还没有上次记录。
- `UNMEASURABLE`：有上次记录，但无法量化比较。

### 2.3 设计边界

该趋势只做家庭长期观察提示，不输出医学判断。真正的疾病管理目标仍然使用三期里的个人目标范围比对。

## 3. 资料包脱敏分享

### 3.1 内容范围

脱敏文本只包含：

- 家庭成员数量。
- 慢病专项数量。
- 近期报告数量。
- 当前用药数量。
- 健康问题数量。
- 资料范围摘要。

不会包含：

- 成员姓名。
- 医院名称。
- 药品名称。
- 具体报告指标结果。
- 健康问题明细。

### 3.2 使用方式

App 长期管理区新增“脱敏分享”按钮，直接使用 `privacySafeShareText` 调起系统分享。

完整资料包、长图资料包仍保留原能力。脱敏版只是多一个低风险概览选择，不会影响原来的资料包明细查看和分享。

## 4. App 展示

长期管理卡片新增：

- “手动趋势”统计项。
- 最近三条手动指标趋势摘要。
- “脱敏分享”按钮。

指标趋势和目标趋势并存：

- 手动趋势来自用户日常记录。
- 目标趋势来自慢病个人目标和近期报告指标。

二者数据来源不同，展示时不能互相替代。

## 5. 后续方向

四期后还可以继续做：

- 日常指标趋势图。
- 成员维度的脱敏范围选择。
- 资料包模板和分享前预览。
- 家庭协作者真实分派表。
- 药品知识库规则。

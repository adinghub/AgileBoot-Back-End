# 后台健康系统菜单权限设计

## 1. 文档目标

本文档用于收口当前 PostgreSQL 基线下的健康系统后台菜单、按钮权限和落库脚本口径，确保新环境执行后即可直接看到后台健康菜单。

当前文档以 2026-04-23 当前仓库实现为准。

## 2. 当前菜单脚本

当前应使用的 PostgreSQL 菜单脚本为：

1. `sql/pgsql/健康系统_后台管理菜单权限_20260423.sql`

说明：

1. 该脚本依赖 `sys_menu`、`sys_role_menu` 已由 `sql/pgsql/健康系统_schema_20260423.sql` 一体化初始化脚本创建
2. 脚本采用 PostgreSQL 语法，直接使用默认 schema，不再依赖 `app` schema 前缀
3. 脚本按自然键幂等写入，不依赖 MySQL 用户变量

## 7. 执行建议

推荐执行顺序：

1. 先执行 PostgreSQL 基础库 schema/data 脚本
2. 再执行 `sql/pgsql/健康系统_schema_20260423.sql`
3. 最后执行 `sql/pgsql/健康系统_后台管理菜单权限_20260423.sql`
4. 后台重新登录，刷新动态路由缓存

## 8. 校验建议

建议执行：

```sql
SELECT menu_id, menu_name, parent_id, path, permission
FROM sys_menu
WHERE path LIKE '/health%'
   OR permission LIKE 'health:%'
ORDER BY menu_id;
```

确认以下页面菜单都已存在：

1. `/health`
2. `/health/drug`
3. `/health/message`
4. `/health/indicatorTemplate`
5. `/health/familyShare`
6. `/health/medicationHistory`
7. `/health/operationTask`
8. `/health/report`

# 健康洞察记录指标关联慢病档案说明

## 1. 背景

健康洞察里的“记录指标”已经能保存血压、血糖、体重、心率等日常指标，并写入通用慢病日记。

原交互里，用户只能手动填写慢病档案 ID 或慢病编码。这对普通用户不友好，也容易填错成员或档案。

因此本次调整为：记录指标时可以直接选择当前家庭成员下的慢病档案。

## 2. 产品目标

1. 用户记录指标时先选择家庭成员。
2. App 根据所选成员展示可选慢病档案。
3. 用户可以不关联慢病档案，继续保存普通日常指标。
4. 用户选择慢病档案后，病种编码自动带入。
5. 保存后，指标记录仍进入统一健康时间线和慢病日记链路。

## 3. 交互规则

记录指标弹窗包含以下关键项：

1. 家庭成员。
2. 慢病档案，可选。
3. 指标类型。
4. 指标数值、单位、测量场景和备注。

切换家庭成员时，已选择的慢病档案会被清空。

如果当前成员没有可选慢病档案，页面展示“不关联慢病档案”，用户仍可以继续保存指标。

## 4. 保存规则

选择慢病档案后，保存内容会携带：

1. 家庭成员 ID。
2. 慢病档案 ID。
3. 慢病档案对应的病种编码。
4. 指标类型和指标数值。

未选择慢病档案时，保存内容只绑定家庭成员和指标信息。

## 5. 后端校验

后端保存时会校验：

1. 当前账号必须能编辑该家庭成员。
2. 如果传入慢病档案 ID，该档案必须属于本次记录的家庭成员。
3. 已关闭的慢病档案不能再作为日常指标关联对象。
4. 选择档案时，病种编码以后端档案快照为准，避免前端传错编码。

## 6. 验收点

1. 打开记录指标弹窗后，可以看到慢病档案选择项。
2. 切换家庭成员后，慢病档案列表随成员变化。
3. 选择慢病档案后，慢病编码自动填入。
4. 不选择慢病档案也可以保存日常指标。
5. 不能把 A 成员的指标记录关联到 B 成员的慢病档案。
6. 保存成功后，健康洞察刷新并能在日记或时间线中看到该记录。

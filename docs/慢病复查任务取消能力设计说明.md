# 慢病复查任务取消能力设计说明

## 1. 背景

慢病专项已经支持一键创建复查任务。创建后，任务会进入首页待跟进任务流，并在慢病专项详情中展示“已安排复查”。

但用户在实际使用中可能会遇到以下情况：

1. 点错了复查任务。
2. 复查时间已经线下重新安排。
3. 当前慢病专项暂时不需要提醒。
4. 想先取消旧提醒，再重新创建新的复查时间。

因此需要支持“创建复查任务后可以取消”。在此基础上，用户如果明确想移除误建的复查提醒，也需要支持删除。

## 2. 产品目标

本次目标很明确：

1. 用户能在慢病专项详情中取消已安排的复查提醒。
2. 取消后首页不再展示该复查待办。
3. 取消不删除慢病专项档案。
4. 取消不删除报告、指标、健康问题或慢病日记。
5. 取消后用户仍可重新创建复查任务。
6. 用户可以删除误建的复查提醒，删除后不再出现在首页和慢病专项看板。

## 3. 业务规则

### 3.1 可取消对象

只允许取消当前慢病专项下已经生成的复查任务。

复查任务必须满足：

1. 任务属于当前慢病专项。
2. 任务类型是慢病复查。
3. 当前账号拥有该家庭成员的编辑权限。

### 3.2 取消后的状态

取消后只关闭任务本身：

1. `operation_task.status` 置为停用。
2. `operation_task.end_time` 置为当前时间。
3. 任务备注追加“已取消复查提醒”。

这样做的原因是：

1. 当前任务不再进入待办列表。
2. 任务记录仍可用于后续排查。
3. 不影响后续重新创建复查提醒。

### 3.3 不做的事情

本次不做以下改动：

1. 不删除慢病专项。
2. 不删除复查历史。
3. 不改健康问题状态。
4. 不改报告指标。
5. 不增加新的任务表。

### 3.4 取消与删除的区别

取消和删除都只作用于复查提醒，不作用于慢病专项档案本身。

二者区别如下：

1. 取消：把 `operation_task.status` 置为停用，追加“已取消复查提醒”备注，任务记录仍作为普通状态保留。
2. 删除：先把任务置为停用并追加“已删除复查提醒”备注，再走 `operation_task` 逻辑删除。

删除适合用户误建复查提醒后希望从当前看板彻底移除的场景。删除后仍可重新创建新的复查任务。

## 4. App 交互

慢病专项详情中，如果已经存在复查任务：

1. 展示“已安排复查”卡片。
2. 卡片内展示复查日期和任务说明。
3. 卡片内新增“取消复查提醒”按钮。
4. 卡片内新增“删除复查提醒”按钮。
5. 点击取消或删除时都弹出二次确认。
6. 确认后处理该复查提醒，并刷新当前慢病专项详情。

取消成功后，原“已安排复查”卡片消失，页面重新展示“创建复查任务”按钮。

删除成功后，原“已安排复查”卡片同样消失，页面重新展示“创建复查任务”按钮。

## 5. 后端处理

后端新增取消命令对象：

```java
CancelChronicDiseaseReviewTaskCommand
```

命令中只包含可选备注，用于记录取消原因。

应用服务新增取消方法：

```java
cancelReviewTask(profileId, operationTaskId, command, currentUserId)
```

应用服务新增删除方法：

```java
deleteReviewTask(profileId, operationTaskId, currentUserId)
```

服务内部处理顺序：

1. 读取慢病专项。
2. 校验当前账号是否可以编辑该专项所属成员。
3. 读取复查任务。
4. 校验任务属于当前慢病专项。
5. 校验任务类型是慢病复查。
6. 将任务置为停用并写入结束时间。
7. 追加取消备注。

删除处理顺序与取消一致，但最后会执行逻辑删除，确保该复查提醒不再被当前看板、首页待办和后续查询读取。

## 6. 验收点

1. 慢病专项没有复查任务时，只展示创建按钮。
2. 创建复查任务后，详情中展示已安排复查卡片。
3. 已安排复查卡片中有取消按钮。
4. 点击取消时有二次确认。
5. 取消成功后卡片消失。
6. 取消成功后首页不再出现该复查待办。
7. 取消后可以重新创建复查任务。
8. 无权成员不能取消复查任务。
9. 不能用一个慢病专项取消另一个慢病专项的复查任务。
10. 已安排复查卡片中有删除按钮。
11. 点击删除时有二次确认。
12. 删除成功后卡片消失。
13. 删除成功后首页不再出现该复查待办。
14. 删除后可以重新创建复查任务。

## 7. 后续可扩展

后续如果要继续增强，可以考虑：

1. 取消时让用户填写原因。
2. 在慢病专项详情展示最近一次取消记录。
3. 支持复查任务改期，而不是只能重新创建。
4. 首页待办详情中也提供相同的取消能力。

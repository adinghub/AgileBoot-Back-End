# 体检报告趋势与指标模板设计

## 1. 目标

本设计覆盖两块二期能力：

1. 报告趋势对比
2. 指标模板后台维护

## 2. 指标模板

### 2.1 设计目的

在录入报告指标时，前端不一定每次都能完整填写参考范围与单位，因此引入后台模板表：

`health_indicator_template`

模板作用：

1. 自动补齐结果单位
2. 自动补齐参考范围
3. 预留建议模板内容

### 2.2 匹配规则

当前优先级：

1. `report_type + item_code`
2. `report_type + item_name`

若命中模板，则只补齐前端未填写的字段，不覆盖人工录入值。

## 3. 报告趋势对比

### 3.1 设计策略

当前采用“以当前报告为基准，对比同成员、同报告类型的历史报告”。

优势：

1. App 进入报告详情即可直接看到趋势
2. 不要求前端额外选择指标或历史范围
3. 适合移动端详情页和卡片式展示

### 3.2 匹配逻辑

当前指标匹配键：

1. 优先 `item_code`
2. 若 `item_code` 缺失，则退回 `item_name`

### 3.3 输出内容

每个趋势项包含：

1. 当前结果
2. 上次结果
3. 变化方向
4. 变化说明
5. 历史点位列表

## 4. 与共享权限的关系

报告趋势也复用家庭共享权限：

1. `OWNER` 可查看
2. `EDITOR` 可查看
3. `VIEWER` 可查看

指标编辑、报告上传、删除则要求 `canEdit = true`。

## 5. 后台维护范围

后台已提供模板管理接口，支持：

1. 列表
2. 详情
3. 新增
4. 修改
5. 删除

建议后续后台页面展示字段：

1. 报告类型
2. 指标编码
3. 指标名称
4. 单位
5. 参考范围
6. 建议模板
7. 状态
